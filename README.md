# 🚀 GATE CSE Quiz App

An interactive quiz application designed for GATE CSE preparation, built using HTML, CSS, and JavaScript.

## ✨ Features

- 📝 10 CSE questions
- ⏱️ 30-second timer for each question
- 📊 Progress bar
- ✅ Correct answer feedback
- ❌ Wrong answer feedback
- 🎯 Score tracking
- 🏆 Final result
- 🔄 Restart quiz
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start the quiz.
4. Select an answer and click **Next**.

## 🎯 Purpose

This project was created as a practical web development project while learning JavaScript and preparing for GATE CSE.
